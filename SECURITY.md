# Security policy

## Reporting a vulnerability

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/elarion-game-dev/otrosko-animiranje-ema/security/advisories/new).
Don't open a public issue for them.

You'll get a reply within a few days. Please give reasonable time to fix the problem before you disclose it.

## Scope

- The website at https://elarion-game-dev.github.io/otrosko-animiranje-ema/ (pages, scripts, Content Security Policy)
- The editor at `/admin/`, its use of the GitHub API and the password-protected access file

Out of scope: the form services (report those to the provider), and GitHub Pages itself.
